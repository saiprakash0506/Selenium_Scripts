 Selenium Execution Sequence (Workflow Steps) - YOUTUBE VIDEO DOWNLOADER
 
Step 1: Initialize the Chrome WebDriver instance, maximize the browser window layout, and configure explicit waits (WebDriverWait).

Step 2: Navigate directly to the YouTube homepage (https://www.youtube.com).

Step 3: Locate the search bar element, input the target topic query ("Ayar Sheer"), and submit the form.

Step 4: Open the YouTube search filters menu and apply the "This year" upload date constraint.

Step 5: Re-open the filters menu and apply the "Popularity" sorting constraint to surface the top-performing video.

Step 6: Locate the first video result (index[1]), smoothly scroll it into the center of the viewport, and click to open the watch page.

Step 7: Extract the video's live URL, copy it to the system clipboard via pyperclip, and execute an internal JavaScript snippet to immediately pause video playback.

Step 8: Open an isolated browser tab workspace and navigate to the HighReach video downloader utility page.

Step 9: Find the primary text input field on the downloader page and paste the extracted YouTube video URL.

Step 10: Target the main "Download YouTube Video" submission button using normalize-space() and trigger a hardware-level click sequence using ActionChains.

Step 11: Wait for the server to process the video data, locate the "Media found" section text anchor, and smoothly scroll the viewport down to the results.

Step 12: Target the first available resolution option row, isolate its native HTML5 anchor download link (<a>), and execute a JavaScript click to trigger the local file download.
